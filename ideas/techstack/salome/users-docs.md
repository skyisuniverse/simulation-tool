#  User’s Documentation

This chapter provides description of graphical user interface of SALOME platform. Please use links below to learn about GUI features of particular SALOME module.

[GUI module](https://docs.salome-platform.org/latest/gui/GUI/index.html)

This section contains SALOME GUI module documentation. It provides a description of the basic functionalities available in the SALOME GUI desktop.

[Shaper module](https://docs.salome-platform.org/latest/gui/SHAPER/index.html)

This section contains the documentation on the SALOME Shaper module. Shaper is a CAD modeler which came as a replacement for the former Geometry module.

[Geometry module](https://docs.salome-platform.org/latest/gui/GEOM/index.html)

This section contains the documentation on the SALOME Geometry module. This module can be used for creation/editing of the CAD models.

[Mesh module](https://docs.salome-platform.org/latest/gui/SMESH/index.html)

This section contains the documentation on the SALOME Mesh module. This module can be used for generating mesh from the CAD model.

Meshing plug-in modules:

[MG-Tetra plugin module](https://docs.salome-platform.org/latest/gui/GHS3DPLUGIN/index.html)

[MG-Hexa plugin module](https://docs.salome-platform.org/latest/gui/HexoticPLUGIN/index.html)

[Gmsh plugin module](https://docs.salome-platform.org/latest/gui/GMSHPLUGIN/index.html)

[YACS module](https://docs.salome-platform.org/latest/gui/YACS/index.html)

This section contains documentation on the SALOME YACS module. YACS is an alternative implementation of the Supervisor module, that has replaced SUPERV since SALOME series 4x.

[HexaBlock module](https://docs.salome-platform.org/latest/gui/HEXABLOCK/index.html)

This section contains documentation on the SALOME HexaBlock module. This module aims at helping users to build hexahedral meshes by creating of a model of the blocks.

Homard module

This section contains documentation about SALOME Homard module. This module provides means for the adaptation of the mesh generated by the Homard solver for the SALOME platform.

[English version](https://docs.salome-platform.org/latest/gui/HOMARD/en/index.html)

[French version](https://docs.salome-platform.org/latest/gui/HOMARD/fr/index.html)

This section contains documentation about SALOME ADAO module. This module provides data assimilation and optimization features in Python or SALOME context.
