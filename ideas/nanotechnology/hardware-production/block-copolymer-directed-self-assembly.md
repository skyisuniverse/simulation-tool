# Block Copolymer Directed Self-Assembly (DSA)

> What is Block Copolymer Directed Self-Assembly (DSA) ?

**Block Copolymer Directed Self-Assembly (DSA)** is **a manufacturing method that uses the natural, chemical tendency of specific molecules to self-organize into perfect, ultra-fine geometric patterns**.

Instead of using a multi-billion-dollar laser to painstakingly draw nanometer-scale features onto a computer chip, DSA allows chemistry to do the heavy lifting. It is a hybrid "top-down" and "bottom-up" approach to nanomanufacturing.
