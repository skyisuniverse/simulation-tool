# SDK

From conversation with Gemini on [SDK](https://share.google/aimode/erDuyuVoBPgJo0hBt)

An **SDK** stands for `Software Development Kit` (also known as a devkit). It is a collection of:

- pre-built tools, 
- code libraries, 
- documentation, 
- debugging facilities, 
- and application programming interfaces (APIs) 

provided to developers so they can build software applications quickly for a specific platform or operating system.

## What’s Inside an SDK?

- **Code Libraries / Frameworks**: Pre-written blocks of code that handle common functions so you don't have to write them from scratch.

- **APIs (Application Programming Interfaces)**: Rules and protocols that let your app communicate with external services or the operating system.

- **Compilers and Debuggers**: Tools to translate human-readable code into executable machine code and find/fix errors.

- **Documentation and Guides**: Manuals, tutorials, and code samples showing how to use the tools.

## SDK vs. API: What is the Difference?

- An **API** is a messenger or set of rules that allows two programs to talk to each other.
- An **SDK** is a full toolkit (like a complete workshop or an IKEA box with parts, tools, and a manual) that usually contains APIs alongside libraries, compilers, and documentation to build a whole application.

## Common Examples

- **Mobile SDKs**: Android SDK for Android apps or iOS SDK for iPhone apps.

- **Cloud & Services SDKs**: AWS SDKs for connecting applications to Amazon Web Services using languages like Python, .NET, or Ruby.

- **Game & Feature SDKs**: Toolkits for adding payments, maps, login systems (like Sign in with Google), or ad networks into a game or mobile app.
